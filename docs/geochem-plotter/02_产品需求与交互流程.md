# 产品需求与交互流程

按[正式任务书v2](../../GeoPlot_科研绘图工具_正式任务书_v2.md)执行；控件参数和保存行为以其第5–10节及15的schema1.1为准。AstroMat不在本期。

## 1. 面向谁、解决什么

面向地球化学研究者，核心场景是把自己测得的月球样品与嫦娥、Apollo 文献数据放到相同图解中比较。用户无需先在 Excel 中手动拆分每种矿物、复制样品列和重复做标准化。

第一版语言以中文为主，图中文字可选择英文；工作台浅色、清晰、操作密度适中。用数据和图作为视觉中心，不做大面积装饰背景。

## 3. 六步用户流程

### 第一步：建项目、上传工作簿

入口提供“新建项目”“打开项目”“内置数据库”“上传数据”“图件库”“导出记录”。首次登记13所列的6个目录项，使用旧数据无需重复上传。上传后列出每个子表的名称、行列数和建议角色。用户可以同时选多表；Normalization value建议为参考组成，trace表建议为派生视图。

读取大表使用后台任务，显示已扫描行数/总行数、当前子表、取消按钮。失败时保留已上传文件和用户映射，允许重试；取消不产生半完成数据集。默认不加载 `~$` 锁文件。

### 第二步：确认导入含义

向导四页：**选表 → 映射 → 问题检查 → 导入结果**。

映射页左侧原列（显示列号，如 Z:La 与 BK:La），右侧规范字段、单位、数据状态（原始/已标准化/比值/误差）。显示至少前 20 行，支持跳转问题行。支持选择表头和数据起始行、忽略空列及重复表头。

未知单位、无法确认的参考组成、多个通道冲突只阻止相关量参与计算，不阻止其他明确字段入库。提供批量设定单位和分类，不要求用户逐行编辑几万条记录。

检测到重叠表时呈现“主表 / 派生视图 / 独立分析”选择，展示匹配证据和影响记录数。默认保留所有来源，不将重叠记录作为新的独立点。

### 第三步：选研究对象

左侧筛选树顺序：**数据来源 → 任务 → 分析对象 → 矿物 → 母样品 → 测点**；来源和任务是不同维度。

示例：

```text
我的实验数据
  CE6
    矿物 → 辉石 → CE6-129 → 各测点
    玻璃 → CE6-118 → 各测点
文献数据
  CE5 / CE6
  Apollo → 全岩 → 74235 → 74235,52 / 74235,62 / 其他子样
```

树只是分面查询视图，不得用前端载入全部数据重新生成分类。未知类别单独显示“待确认”，不可并到全岩。

样品搜索默认“精确名字”，旁边有“母样品”“包含关键词”模式。输入 74235 后能明确看到 4 条精确记录与 14 条母样品记录的区别；换页、排序、搜索不能丢勾选。

提供“选择当前页”“选择全部筛选结果”“取消当前筛选结果”“清空本图选择”，每项文案包含影响数量。表格筛选仅改变可见记录；改变已投图记录须通过选择操作。

### 第四步：选择图解与变量

四类图模板在顶部可见。选图后按所需字段显示覆盖率，列表按可用字段排序，但缺失项仍可搜索到并看到不可用原因。

- 散点：X / Y 由变量选择器生成，例如 `La (ppm)`、`Rb/Sr`、`La_N`、`(La/Yb)_N`。
- REE：预置元素顺序，选择参考组成，展示每条曲线有效 REE 数。
- 蛛网：选择元素序列和参考组成；标准不覆盖的元素显示具体名称。
- TAS：明确 `SiO2 (wt%)`、`Na2O + K2O (wt%)`，只展示符合所选模式的数据。

变量编辑器不接受任意 Python/JavaScript。首版使用选择式操作和有限表达式 AST，运算规则见 03。

### 第五步：添加对比与美化

点击“添加对比数据”后选择已导入数据集或再上传；每组独立保存筛选和颜色，支持 CE5、CE6、Apollo 74235、自有数据同时存在。对比数据不会被自动作为标准化参考值。

默认自己的数据在上层，参考数据适当降低透明度。颜色区分来源/组，点形区分分析对象；图例明确组名和 n。不同矿物/全岩混合在同一图时保留分组，不自动合并均值。

导出模式显示真实 mm 尺寸的版式预览；字号按 pt 定义，不能随着浏览器缩放改变论文配置。样式可另存模板并应用到其他图。

### 第六步：导出与继续工作

选择单栏/双栏、自定义尺寸、SVG/PDF/PNG、PNG dpi。导出前显示数值快照、有效点数、缺失/排除、参考来源、未确认元数据和字体替代信息。

点击导出后冻结图件版本和Scene，真实写入用户选定的本机目录；全部校验和提交后才显示成功及完整路径，提供打开文件夹和下载副本。继续改变页面不会影响正在导出的图。复现包包含图文件、投图数据、配置、参考值、源记录位置、排除清单。具体事务、失败和记录要求见主任务书第8–9节。

保存后关闭程序再打开，数据、选择集、参考组成版本、样式和图层状态一致。

## 4. 布局规范

```text
顶栏：项目名 | 导入 | 保存 | 撤销/重做 | 导出
左栏 280 px       中央可伸缩绘图区             右栏 320 px
来源/任务/材料     图类型与图层标签             变量/参考值/样式
样品与选择集      交互画布 + 出版预览切换       图例/坐标/输出尺寸
底栏：可折叠数据表，显示原始值/计算值/来源/质量标志
状态栏：已选分析 14 | 独立母样品 1 | 本图有效 12 | 排除 2（可点开）
```

1440×900 和 1920×1080 是主验收尺寸；1366×768 时侧栏可折叠，不得遮挡绘图区或导出按钮。移动端允许简化查看，不承诺完整编辑器。

## 5. 必须覆盖的异常状态

| 状态 | 用户看到什么 | 恢复方式 |
|---|---|---|
| 没有文件/没有选样 | 简短说明 + 唯一主操作 | 导入/选择样品 |
| 本图无有效值 | 所需字段、排除原因和记录数 | 改变量/修映射/换样品 |
| 标准不覆盖元素 | 缺少哪些值，哪些曲线受影响 | 换标准/显式删元素/补参考值 |
| 大量曲线重叠 | 当前曲线数与性能提示 | 分组、筛选或使用明确的汇总模式 |
| 未知单位/重复字段 | 指向原表列号的修复入口 | 批量确认映射，不猜测 |
| 请求超时/后端断开 | 保留当前编辑，提供重试 | 恢复服务后重试 |
| 有旧图新配置尚未算完 | 图标注“旧版本预览” | 成功回包后替换，禁止旧图导出 |

## 6. 可操作性验收

首次导入含审计步骤；完成一次映射后，同结构文件可复用。已导入项目中，选择保存的 CE6 辉石组、添加 Apollo 74235 对比、切换 REE、导出 PDF，目标不超过 8 次主要点击（不计输入文字和可选美化）。此目标是交互验收用例，不能删掉必要的科学参数确认来凑数。
