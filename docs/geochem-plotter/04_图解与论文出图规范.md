# 图解与论文出图规范

v2控件完整范围见[正式任务书第5–6节](../../GeoPlot_科研绘图工具_正式任务书_v2.md)，参考资源见[13](13_内置数据与参考组成清单_v2.md)，交互与写盘验收见[16](16_v2交互导出启动验收.md)。本文件的期刊预设数值不限制用户在自定义模式下调整。

## 1. 四类首版图解

| 图解 | 输入、默认设置 | 必须可交互 | 验收重点 |
|---|---|---|---|
| 自定义 X–Y | 两个表达式；linear/log 各自可选 | 换元素/比值/标准化值、框选、误差开关 | 原始 ppm、Rb/Sr、(La/Yb)_N 不混淆 |
| REE | La Ce Pr Nd Sm Eu Gd Tb Dy Ho Er Tm Yb Lu；默认标准化、log Y | 样品/组开关、参考表切换、元素增删重排 | 顺序正确、不含 Pm、缺值断线、无二次标准化 |
| 多元素蛛网 | 产品默认序列 Cs Rb Ba Th U Nb Ta La Ce Pb Pr Sr Nd Zr Hf Sm Eu Ti Gd Tb Dy Y Ho Er Tm Yb Lu | 可选命名序列、保存自定义序列 | 序列不是万能文献标准；参考组成必须逐元素覆盖 |
| TAS 参考图 | SiO2 与 Na2O+K2O，wt%，默认全岩 | 显示/隐藏分区名、坐标、样品来源，原始/无挥发分模式 | 不把 Si 当 SiO2，不给矿物定岩石名，不凭截图描线 |

P0 所有图都支持单个分析点/曲线、自有和文献多图层、颜色点形线型、数据源追溯。REE 和蛛网可切原始浓度模式，但 Y 标签必须随之改变。用户参考表只含 REE 时，REE 正常工作，多元素蛛网必须先更换/补齐参考表或显式缩小元素集合。

## 2. 参考组成

首版交付三个可用入口：

1. 从当前工作簿导入的自定义 14 REE 表，出处未确认时名称始终保留“自定义”；单位由用户确认。
2. 用户自定义参考 CSV/XLSX，至少 `element,value,unit,reference`；拒绝重复元素、非正值和未知单位。
3. 固定内置`Chondrite_MS95@1`（14REE）与`PM_SM89@1`（27元素）；数值已按pyrolite维护者公开参考数据库核对，精确值与出处见13及其CSV。Qoder必须检查封装后的值逐项一致并记录hash，不能自行换另一套CI/PM。验证等级写“数值数据库核对”，不冒称已读取原论文原表。

参考组成和“对比样品”是不同功能：Apollo 74235 曲线不是一套默认标准化常数。任何引用同名但值不同的标准都存不同 version 和 hash。页面能展开完整参考值表，出图附带名称、年份/自定义标记。

## 3. TAS 分区实现门槛

- 文献源头：[Le Bas et al. (1986)](https://doi.org/10.1093/petrology/27.3.745)；实现需明确所用后续几何版本。
- 可复用 [pyrolite 的 TAS 模型](https://pyrolite.readthedocs.io/en/develop/examples/util/TAS.html)，但它存在 Middlemost、LeMaitre 等变体。**不能用默认模型后标注成另一个版本**。
- Qoder在`backend/app/resources/diagrams/tas_manifest.json`写明模型、作者年份、来源URL、依赖/数据版本、许可和几何哈希。固定采用pyrolite的`LeMaitre`变体，资源ID=`tas_LeMaitre@1`；界面和图注按实际资源来源命名。
- 分区边界使用机器可读坐标；交互与导出共享同一边界，禁止截图背景和肉眼描线。TAS 分区和坐标轴都必须是矢量。
- 测试分区内点、边界点、外域点；边界点返回 on_boundary，不能静默偏移点。月球图的对外结果只叫“参考区域”，不能输出缺乏适用依据的正式岩石命名。
- 本任务书未抄录未经核实的边界坐标。若来源暂不可得，可完成散点/REE等独立任务，但 TAS 验收不得打勾。

## 4. 国际期刊预设与中文论文预设

国际期刊预设依据 Nature 当前官方图稿指南，作为可调整模板而非接受发表的保证。Nature 指南要求可编辑文本和矢量图、标准无衬线字体、清楚轴单位与无装饰干扰的画面。具体期刊/投稿阶段有差异，不能把所有 Nature Portfolio 期刊共用一组固定参数。[官方格式规范](https://research-figure-guide.nature.com/figures/preparing-figures-our-specifications/)

| 参数 | nature_main_2026 默认 | 可调整范围/原则 |
|---|---|---|
| 画布 | 白底；单栏 89 mm、双栏 183 mm | 自定义 mm；Nature 模板高度不超过 170 mm |
| 正文/轴标题 | Arial，7 pt | 模板预检 5–7 pt；最终物理尺寸判断 |
| 刻度/图例 | Arial，6 pt | 最小 5 pt，不能为挤图例无限缩小 |
| 面板字母 | a, b, c；8 pt、正体加粗 | 普通标签不加粗，P1 面板模式启用 |
| 轴/分区线 | 0.6 / 0.45 pt | 细但可读，层次低于数据 |
| 数据线 | 0.8 pt；对比曲线可 0.6 pt | 保持缩印后可辨 |
| 标记 | 3 pt，轮廓 0.35 pt | 自有数据 3.5–4 pt 可选 |
| 图例 | 黑字，按颜色+点形/线型识别 | 外置/内置可调；n 的口径明确 |
| 网格 | 默认关闭 | 用户主动启用浅辅助线时保存配置 |
| 色彩 | RGB，色盲友好，避免彩虹色图 | 组数多时用点形/线型或分面，不循环同色冒充不同组 |

宽度、字体和格式要求来自 [Nature 图形布局与导出指南](https://research-figure-guide.nature.com/figures/building-and-exporting-figure-panels/)。这里的线宽、标记大小、组默认颜色是本产品设计值，不声称是期刊硬性规定。

建议组颜色：自有数据 `#D55E00`，CE5 `#0072B2`，CE6 `#009E73`，Apollo `#6B6B6B`；必须可改。材料用圆/三角/方形区分，图例把组名与材料写清。颜色键由稳定 group_id 决定，筛选或排序不导致颜色漂移。

中文论文预设单列为 `thesis_cn`：中文仿宋，英文、数字和符号 Times New Roman；字号可以大于 Nature 模板。不要把中文论文的字体规则混入国际期刊预设。检测不到指定字体时明确替代字体，预览和导出保持一致。

上下标必须真实排版，例如 SiO₂、Na₂O、(La/Yb)ₙ；不可在画布显示原始 HTML/TeX 标记。纵轴用 `Sample / reference` 或具体 `Sample / CI chondrite`，来源未确认则用 `Sample / custom reference`。

## 5. 交互图与出版图共用什么

共享冻结 PlotScene：有效数值、单位、曲线点序、断线、分组样式、轴范围、刻度语义、分区坐标、图例和注释位置。前端只做渲染和交互，不重新求比值。

图上缩放可作为临时观察；“使用当前视野导出”才写回 PlotSpec 的轴范围。点选只是高亮；“应用高亮到选择集”才改变数据。悬停临时信息不进入论文图。

Plotly 与 Matplotlib 的字距可能不同，数值与语义必须一致；提供由同一 Matplotlib 导出路径生成的“最终版式预览”，不要承诺浏览器交互画布像素级等同 PDF。

## 6. 文件导出

- **PDF**：优先投稿格式；使用内嵌 TrueType 字体，验证 `pdf.fonttype=42` 的实际结果。检查文本可选取、无 Type 3、无缺字。
- **SVG**：文本保留 `<text>` / `<tspan>`，不得把所有文字轮廓化；轴、线、点、边界保持矢量。`svg.fonttype='none'` 可作实现起点，仍须检查导出内容。SVG 字体外观依赖接收机器字体，另存字体清单；不随项目分发无再分发许可的商业字体。[Matplotlib 官方说明](https://matplotlib.org/stable/users/explain/fonts.html)
- **PNG**：预览和通用高分辨率用途，默认 600 dpi，可选 300/600/1200。固定物理尺寸重新渲染，不是把低分辨率图片放大。89 mm @600 dpi ≈2102 px，183 mm ≈4323 px；容许整数取整 ±1 px。
- 不把 PNG 标成 Nature 主图提交文件；主图优先 PDF/SVG，PNG 可用于预览或其他期刊指定用途。其他期刊格式、TIFF/EPS 支持放 P1。
- 一般图不设置 `bbox_inches='tight'` 后任其改变承诺的物理尺寸。布局在固定画布内解决，导出校验实际页面/像素尺寸。
- 超密集背景若用户选栅格化，必须单独标识哪些 layer 被栅格化、dpi 与原因；默认保留矢量。不得把整图截图包装成 SVG/PDF。

## 7. 复现包和视觉验收

复现包包含 `figure.svg/pdf/png`（用户选定格式）、`plot_spec.json`、`scene.json`、`plot_data.csv`、`excluded_records.csv`、`reference_snapshot.json`、`provenance.json`、`font_manifest.json`、`README.md`。数据表列出分析 ID、原始量、单位、参考值、转换后值、来源表/行/列；不能只导出屏幕可见分页。

P0 人工检查四张图，每张在最终单栏或双栏尺寸以及 200% 放大下查看：无裁切、文字重叠、图例遮点、缺字、错单位、意外连线；灰度下用形状/线型仍能区分主要组。保留检查截图与实文件。不能仅凭“导出 HTTP 200”宣布论文图合格。
