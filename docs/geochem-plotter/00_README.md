## 3. 默认方案与边界

| 选择 | 本期决定 | 原因 |
|---|---|---|
| 使用方式 | Windows10/11 x64便携包 + 三按钮启动窗口 + 本地浏览器；同一包支持有/无Python和Node | 自带运行依赖，离线、普通用户可用，不修改系统环境 |
| 后端 | Python 3.12、FastAPI、Pydantic、SQLAlchemy、SQLite、openpyxl、NumPy、Matplotlib | 同一计算内核负责预览数据和导出 |
| 前端 | React、TypeScript、Vite、TanStack Table/Virtual、Plotly.js | 大表筛选、点表联动、撤销和复杂布局 |
| 数据存储 | SQLite 保存规范记录与项目；文件目录保存原始上传副本、导出与审计 | 首版不引入服务器数据库、账号和云服务 |
| 科研绘图 | 后端统一计算 PlotScene；Plotly 交互预览；Matplotlib 生成出版图 | 防止浏览器与导出分别计算导致数值漂移 |
| 启动与封装 | Tkinter启动窗口、pystray托盘、PyInstaller onedir；前端预构建 | GeoPlotLauncher.exe为P0，额外MSI安装器可延后 |

库的精确版本由Qoder在S0验证后写入锁文件，不在任务书中虚构未来安装兼容性。不得在做一半时改换整套架构。

本期不做自动搜文献、AI 自动分类岩石、在线付费服务、用户权限系统、地球化学反演、ML 模型或完整 Excel 编辑器。外部对比数据首先通过**本地文件导入**，常用数据集可保存后重复调用。
