# 数据模型与科学计算规则

本文件定义基础科学语义，与[正式任务书v2](../../GeoPlot_科研绘图工具_正式任务书_v2.md)共同执行；接口字段见05和15。不得在前端另写一套标准化、单位或样品身份算法。

## 1. 三层记录与来源

| 对象 | 含义与必备字段 |
|---|---|
| SourceFile | file_id、原文件名、SHA-256、导入时间、原始副本路径；不可原位修改 |
| SourceRow | file_id、sheet_name、row_number、原单元格/公式/缓存、mapping_version、问题列表 |
| Sample | sample_id、mission、parent_sample、subsample、原始名字集合；物理样品身份可待确认 |
| Analysis | analysis_id、sample_id、source_row_id、材料、矿物、岩性、方法、文献、批次；一条分析不能凭同名自动合并 |
| Measurement | measurement_id、analysis_id、analyte、chemical_form、channel、value、unit、value_state、quality_flags、source_cell；误差/LOD 单独关联 |
| ReferenceComposition | ref_id、version、值表、每值单位、文献/自定义来源、校验状态、快照哈希 |
| SelectionSet | id、name、filter_spec、mode、固定 analysis_ids 或动态查询、dataset_versions |
| Figure / FigureDraft / FigureRevision | 图件、可变草稿、不可变保存版本；精确字段与独立修订号见15，PlotSpec以plot_id关联，避免再建另一套PlotDocument持久化 |

analysis_id 在本数据集版本内稳定，例如由 file_hash + sheet + row + mapping_version 派生；重导同一文件同一映射不重复产生数据。重新映射形成新的 dataset_version，并保留 lineage；旧图不得悄悄切换到新数据。

展示给用户的样品号始终是字符串，保留逗号、前导零、大小写和空格原文；搜索键另做规范化。物理样品、子样和分析点三层身份分开。缺名字的分析使用显式“未命名记录：表!行”占位，不能把所有空名合成一个样品。

## 2. 分类字段必须独立

- `dataset_role`: own / literature / comparison / derived_view。
- `mission`: CE5 / CE6 / Apollo / unknown；具体 Apollo 任务另存 `mission_detail`，仅有可靠元数据时填写。
- `batch`: LABLE、MOUNT-2 等；不可混入 mission。
- `material_type`: whole_rock / mineral / glass / soil / clast / separate / leachate / residue / matrix / groundmass / vein / mesostasis / melt_inclusion / unknown。
- `mineral_group`: pyroxene / plagioclase / olivine / oxide / phosphate / other / unknown；`phase` 保留更细的 augite、opx 等。
- `rock_type`: basalt、breccia 等宿主岩性；与分析对象不同。

每个推断字段保存 `raw_value`、`normalized_value`、`rule_id`、`evidence_cells`、`confidence` 和 `confirmed`。优先级：用户已确认值 → 明确的 Analyzed Material/分析对象 → 明确 phase → 经预览确认的样品名规则；岩性不能盖掉分析对象。冲突进入问题清单，不静默“择一”。

同义词字典起点：PX/Pyroxene→pyroxene；AUG/aug→augite（pyroxene）；OPX→orthopyroxene；PL/Plg/Plagioclase→plagioclase；OL/Olv→olivine；Glass/GLASS/K-GLASS→glass。AN 仅在当前实验表映射上下文中按用户确认映射为 plagioclase，不设全局无条件规则。NAN、空值、未知缩写保留 unknown。

## 3. 样品身份规则

- Apollo `74235`、`74235,62`、`74235, 41` 可在明确 Apollo 来源中识别共同母样品 74235；子样号分别保留。
- `742350` 不属于 74235；`15426/27` 不强制归入 15426。
- 实验名 `CE6-129-PX - 1` 可建议 mission=CE6、parent=CE6-129、phase=PX、spot=1，但原名完整保留，规则需可预览和覆盖。
- 不同文献同样品的不同测点必须保留。同一样品均值、重复测量、不同方法不自动当重复。
- `exact_analysis_duplicate` 要基于来源/测量/对象等证据，`possible_same_sample` 只是身份关系。
- trace 表 535 行重叠关系保留到 source_row 层；映射有歧义的行不自动并入某个候选。默认绘图源为主表，派生视图不额外加点。
- 原始实验与汇总可经 source_file、原始/重命名对照、完整数值建立关系；没有确证就标疑似，默认选汇总进行快捷作图，原始记录仍可查询。

## 4. 数值状态、单位与通道

`value_state` 至少包含 raw_concentration / normalized / derived_ratio / source_index / uncertainty / detection_limit。同名 La 的 raw 与 normalized 是两种量，UI 必须可区分。

`quality_flags` 可多选：missing、non_numeric、excel_error、below_detection、zero、negative、unit_unconfirmed、channel_conflict、normalization_unknown、metadata_conflict。值缺失用 null；JSON 中不输出 NaN/Infinity。

- 1 wt% = 10,000 ppm；1 ppm = 1,000 ppb，仅适用于同一种化学量。
- 元素 ppm 与氧化物 wt% 不能仅靠 10,000 换算。显式选择化学计量转换时：`oxide_wt_pct = element_ppm / 10000 × M(oxide) / (n × M(element))`。记录原子量表和版本、化学式和变换链。
- Si→SiO2、Na→Na2O、K→K2O 可以作为显式转换功能；不得把实验表 Si 列直接送入 TAS。
- FeO、FeOT、Fe2O3 和 Fe 元素不互换。派生 FeOT 时明确价态假设，不能同时把 FeOT 和 FeO/Fe2O3 都加入主量总和。
- 字段不带单位时给建议但保留 unconfirmed；只有被确认的量可参与涉及单位的计算。源文献有分块单位时映射按块生效。
- `La139_ppm_mean` 是测量通道名，不等于“仅 139La 同位素丰度”；去除质量数生成元素映射必须保存 channel 原文。
- 多通道同元素先提示选择；禁止对 Zn66/Zn67 或 PbTotal 与单通道直接相加/平均。优先通道策略应按方法/批次配置并写入 PlotSpec。
- 2SE(int)、2SD、LOD 必须按元素与通道绑定，不当浓度列，也不把所有误差统称 1σ。

## 5. 标准化与比值的精确定义

在单位统一、参考值正且有限的前提下：

```text
E_N = C_E / R_E
A/B = C_A / C_B
(A/B)_N = (C_A/R_A) / (C_B/R_B)
Eu/Eu* = Eu_N / sqrt(Sm_N × Gd_N)
Ce/Ce* = Ce_N / sqrt(La_N × Pr_N)
```

首版支持前三项；后两项为 P1（这里提前锁定几何插值定义，若扩展其他定义须单列名称）。标准化值和同单位元素比值无量纲。上述比值不得混合不同参考版本。

分母零/缺失/非有限、所需值未知单位、参考值缺失或 ≤0 时返回 null + reason_code。禁止 epsilon 垫底。比值的分子/分母先做同单位换算；元素与氧化物的除法默认拒绝，除非明确选择不同化学量的有单位表达式模式（P1）。

首版表达式只允许 measurement、normalize、ratio、add（限同单位、同兼容量）、常数；树深度 ≤8，节点 ≤64，禁止 eval、调用函数、文件/网络访问。TAS 的 Na2O+K2O 是已注册同量纲求和操作。

对已经标准化的数值：知道参考组成时可直接用已标准化视图；重新选标准时须回到 raw 值重算。raw 不在时拒绝换标准，不做不透明“去标准化”。未经确认的来源派生值可以显示为只读核对列，不能伪装成软件新计算结果。

## 6. 缺失、检出限与误差

- 空白、`-`、`n.d.`、`bdl`、`<0.01`、Excel 错误分开解析；`<0.01` 保存 qualifier `<` 与 limit=0.01，不保存为精确测定值 0.01。
- 默认低于检出限/负浓度不进入定量比值、标准化和对数图；记录排除原因。正测定值低于已知 LOD 同样标记 censored。
- 默认零值可显示在允许零的线性原始浓度图中，但对数坐标和分母不允许。不得把零等同于缺失。
- 默认不做 LOD/2 替代；如以后提供此策略，需显式开启并与原值分离显示。
- 蛛网缺一个元素：曲线该处断线，不能连接两侧制造连续数据，也不能自动插补。少于 2 个有效点时只显示标记并提示；0 个有效点列为排除。
- 标准化的绝对误差仅在参考值按无误差常数处理的显式假设下为 `u(C)/R`，保留 2SD/2SE 名称。
- 比值误差首版只支持显式选择“独立且同类误差”时的传播：`u(A/B)=abs(A/B)*sqrt((uA/A)^2+(uB/B)^2)`，要求 A、B 非零且误差类型一致；未提供协方差就不宣称完整不确定度。
- log 图的误差区间触及 ≤0 时不截成正数假装完整，隐藏该误差条并提示；测点本身可按质量规则继续显示。

## 7. 聚合与权重

P0 默认每条有效 analysis 一个点/一条曲线；同一母样品多个测点不自动平均。

P1 聚合必须让用户选择“按分析记录”或“先求各物理样品均值再汇总”；否则测点多的样品会被过度加权。默认统计量用中位数与 25–75% 分位区间，注明 n 为各元素的有效样品数；该区间不是置信区间。不同任务/材料/矿物不自动合并，混组需显式指定。

导出保存聚合前 analysis_ids、每元素有效数、统计定义。视觉抽样仅影响预览且明示抽样数/随机种子，不能改变导出或统计；首版优先用筛选避免抽样。

## 8. TAS 与来源指数

TAS 参考比较模式：x=SiO2，y=Na2O+K2O，单位 wt%，默认全岩；月球数据只做参考投图，不自动宣布地球火山岩正式定名。玻璃可在“参考比较”中显式加入；矿物不作为 TAS 岩石分类输入。

100% 无挥发分重算是独立变换，必须显示所用主量项列表。缺主量氧化物不是零；用户确认完整性和 Fe 计入方式后才可重算。每条记录保存原始总和与重算系数。原始氧化物比较模式允许直接画明确 wt% 数据，但不得标注“已符合正式 TAS 分类要求”。

首版重算模板固定十项SiO2、TiO2、Al2O3、FeOT、MnO、MgO、CaO、Na2O、K2O、P2O5；排除H2O、CO2、LOI。每项必须有明确值，实测0可计入，空缺拒绝；总和S必须有限且>0，所有项乘100/S。源为FeO+Fe2O3时，用户显式选择“全部铁按FeO计”，用FeOT=FeO+[2M(FeO)/M(Fe2O3)]×Fe2O3，保留原子量版本，不能再将原FeO/Fe2O3重复加入总和。仅有总Fe元素时先显式化学计量转换，不能暗用。用户若需不同氧化物集合，另存带名称/版本的自定义模板并确认完整性，图注写实际模板；不称通用标准集合。

Mg#、An#、同位素比值等来源已有字段原样保存为 source_index。新建这些科学指数须独立定义化学计量、价态和误差规则，首版不靠复制 Excel 公式自动生成。

## 9. 可复现性和审计

一次成功计算冻结：文件哈希、映射版本、数据集版本、analysis_ids、质量策略、表达式树、标准化表完整快照、TAS 模型版本、样式、软件版本。每个结果点可回查原表行列和全部变换步骤。

筛选器与选样分离：筛选是查找条件；投图选择是稳定的 ID 集。保存动态图组时也必须记录本次执行解析出的 ID 快照。图层隐藏不删除选择；导出以冻结的 visible 状态为准。
